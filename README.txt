창고 물품 관리 프로그램 설치 안내
=================================
구성: index.html(화면) · api.php(PHP용 서버) · server.js(Node.js용 서버) · data/data.json(데이터)
데이터: 엑셀(20260930_수성구청_전자창고_재고수량_1.xlsx) 178종 / 보관장소 57곳이 이미 들어 있습니다.
※ PHP 방식과 Node.js 방식 중 서버 환경에 맞는 한 가지만 쓰면 됩니다.

[방법 A] PHP 웹호스팅 / Apache (PHP 7 이상)
 1. 이 폴더의 모든 파일을 웹서버의 원하는 폴더에 업로드 (data 폴더 포함)
 2. api.php 맨 위의 $PASSWORD = ''; 에 수정용 비밀번호 입력 (비우면 누구나 수정 가능)
 3. data 폴더(와 data.json)에 웹서버가 쓸 수 있는 권한 부여 (예: 폴더 755/775, 파일 664/666)
 4. 브라우저에서 업로드한 폴더 주소 접속 (예: https://내도메인/warehouse/)
 ※ Apache는 data/.htaccess 로 data 폴더가 외부에서 직접 열리지 않게 막아 둡니다.
   Nginx 등은 data/ 경로 접근 차단을 직접 설정하세요.

[방법 B] Node.js 서버 (Node 14 이상, 별도 설치 패키지 없음)
 1. 폴더를 서버에 복사
 2. 실행:   WH_PASSWORD=비밀번호 PORT=3000 node server.js
    (Windows CMD:  set WH_PASSWORD=비밀번호&& node server.js)
 3. http://서버주소:3000 접속. 계속 실행하려면 pm2 또는 서비스 등록을 사용하세요.

사용 방법
 - 조회·QR 스캔은 누구나 가능, 등록/수정/삭제는 비밀번호가 필요합니다.
   (처음 수정할 때 비밀번호를 물으며, 그 기기 브라우저에 기억됩니다.)
 - 위치·QR 탭의 QR은 "지금 접속한 주소"로 만들어집니다.
   반드시 최종 운영 주소(도메인)로 접속한 상태에서 QR을 인쇄하세요.
   (localhost 나 임시 주소로 인쇄하면 그 주소가 QR에 들어갑니다.)
 - 서버 주소가 바뀌면 QR을 다시 인쇄해야 합니다.
 - 백업: data/data.json 파일만 복사해 두면 됩니다.
 - 비밀번호가 평문으로 전송되므로 가능하면 HTTPS 를 사용하세요.

오프라인 사용 (v2)
==================
- 한 번이라도 온라인으로 접속하면 물품·위치 데이터가 그 휴대폰/PC 브라우저에 저장됩니다.
  신호가 없으면 화면 상단에 "📴 오프라인" 표시가 나오고, 저장된 데이터로 조회·검색·QR 스캔 결과가 그대로 표시됩니다.
- 오프라인에서 등록/수정/삭제하면 그 기기에 쌓아 두었다가, 연결이 돌아오면(앱을 열어 둔 상태에서 약 15초 이내) 서버에 자동 반영됩니다.
  상단에 "반영 대기 N건"이 표시되며, 반영이 끝나면 사라집니다. 여러 기기가 같은 물품을 오프라인에서 고치면 나중에 반영된 값이 남습니다.
- 앱 화면 자체를 오프라인에서 다시 열려면(서비스워커) 서버 주소가 반드시 HTTPS 여야 합니다. (localhost 는 예외)
  1) HTTPS 로 운영하는 경우: 휴대폰에서 한 번 접속한 뒤 "홈 화면에 추가"를 해 두세요.
     이후 신호가 없는 곳에서도 홈 화면 아이콘이나 QR 스캔으로 열립니다.
     (아이폰 Safari: 공유 → 홈 화면에 추가 / 안드로이드 Chrome: 메뉴 → 앱 설치)
  2) 내부망 http://192.168.x.x 처럼 HTTP 로 운영하는 경우: 서비스워커가 동작하지 않으므로
     이미 열어 둔 화면은 연결이 끊겨도 계속 사용할 수 있지만, 연결 없이 새로 열 수는 없습니다.
     (서버 PC 와 같은 Wi-Fi 에만 연결되어 있으면 인터넷 없이도 정상 사용 가능)
- 아이폰은 사용하지 않는 사이트의 저장 데이터를 일정 기간 후 지울 수 있으니, 홈 화면에 추가해 두는 것을 권장합니다.
- 업그레이드 시 새로 추가된 파일: sw.js, manifest.webmanifest, icon-192.png, icon-512.png, .htaccess (모두 index.html 과 같은 폴더에 올리세요)

파일 단독 사용 (서버 없이)
==========================
- index.html 안에 엑셀 물품 데이터(178종·위치 57곳)가 들어 있습니다.
  서버 없이 index.html 을 더블클릭하거나 USB 로 복사해서 열어도 전체목록·검색·위치 조회가 됩니다.
- 이 경우 화면 위에 "파일 단독 모드"가 표시되며, 수정한 내용은 그 기기·그 브라우저에만 저장됩니다. (서버와 공유되지 않음)
- 파일 모드의 QR은 그 파일의 경로로 만들어지므로 인쇄해서 붙이는 용도로는 쓰지 마세요.
  (QR 인쇄는 반드시 서버 주소로 접속한 상태에서)
- 서버에 접속한 적이 없는 기기에서도, 서버가 응답하지 않으면 내장된 데이터(엑셀 기준 시점)가 표시됩니다.
  서버에 접속하면 항상 서버의 최신 데이터로 바뀝니다.
- 일부 브라우저(특히 아이폰 Safari)는 파일로 연 페이지에 수정 내용을 저장하지 못할 수 있습니다.
